# SignalGate Acquisition / Due-Diligence Index

Maintain these folders from the first paying provider.

## 01 Corporate and IP
- incorporation/share records;
- founder/contractor agreements;
- IP assignment;
- trademark/domain ownership;
- open-source dependency/licence inventory.

## 02 Product
- architecture;
- data model/migrations;
- roadmap;
- release/change log;
- provider/customer documentation;
- supported integrations/brokers.

## 03 Engineering assurance
- CI history;
- automated/adversarial test inventory;
- dependency/SBOM reports;
- independent review;
- penetration-test reports and remediation;
- incident/postmortem history;
- backup/restore evidence.

## 04 Security/privacy
- threat model;
- access/RBAC model;
- secret-management policy;
- data-flow/retention map;
- DPA/privacy terms;
- subprocessor list.

## 05 Regulatory/legal
- regulatory-perimeter opinion;
- financial-promotion review where applicable;
- provider responsibility schedule;
- customer/provider terms;
- broker/integration agreements;
- complaints/incident obligations.

## 06 Commercial
- signed provider contracts;
- pricing/version history;
- pipeline;
- MRR/ARR;
- churn/retention/expansion;
- customer concentration;
- onboarding and support costs.

## 07 Operations
- infrastructure diagram;
- cloud costs;
- SLO/uptime history;
- support runbooks;
- on-call/escalation;
- disaster-recovery test record.

## 08 Product evidence
- signals processed;
- commands processed;
- execution acknowledgement rate;
- duplicate prevention/replay metrics;
- reconciliation exception rate;
- incident frequency/severity;
- onboarding time;
- active connected demo/live accounts, clearly separated.

A buyer should be able to understand how SignalGate works, how safe it is, who owns it and how it earns money without relying on verbal founder knowledge.
