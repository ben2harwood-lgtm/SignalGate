# SignalGate Acceptance Evidence Templates

This directory contains **blank templates only**.

Do not commit raw credentials, customer/provider personal data, unredacted exploit material, privileged legal advice or confidential third-party reports to the public repository.

Use `docs/ACCEPTANCE_EVIDENCE_INDEX.md` as the public control sheet and store sensitive evidence in the controlled data room. Reference it with a stable receipt identifier.
